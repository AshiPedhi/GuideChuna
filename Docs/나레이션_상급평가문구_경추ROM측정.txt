# 경추ROM측정 — 상급·평가 나레이션 문구
#
# 상급·평가는 CSV voiceInstruction을 통째로 무시하고 stepName 클립만 재생한다.
# 그래서 문구를 따로 쓴다. 원칙은 '수행 방법 미고지' —
#   · 무엇을 할 단계인지만 말하고, 어떻게 하는지는 말하지 않는다.
#   · 파지 부위, 시술자 위치, 관찰 포인트, 각도 기준을 넣지 않는다.
#   · 방향(굴곡·좌/우)은 뺄 수 없다. 어느 방향을 재는지 모르면 평가 자체가 성립하지 않는다.
#   · step당 1회만 재생되므로 한 문장으로 끝낸다.
#
# 형식: stepName|문구
# 생성: generate.py 경추ROM측정 --map Docs/나레이션_상급평가문구_경추ROM측정.txt --levels Advanced --write
#      (Evaluation은 Advanced와 바이트 동일 파일로 복사한다)
#
# ★2026-09-11 개정 (09-10 XR-ROM 2차 회의 — [평가]를 가상환자 대상으로 되돌림)
#   · 문구는 09-09 실측 평가 규격(동작 하나를 명령형 한 문장)을 따른다.
#   · ★단면 용어(시상면·관상면·횡단면)는 말하지 않는다(09-11 사용자 지시).
#     파지는 서는 자리로("환자 측면에서 / 환자 뒷면에서"), 방향은 교과서 명칭(굴곡·신전·측굴·회전)으로.
#     실측 CSV 문구도 같은 날 같은 문장으로 바꿨다.
#   · 파지 3종은 stepName에 공백이 있다('시상면 파지'). 옛 '관상면파지'·'횡단면파지'는 공백이 없어
#     로더와 매칭이 안 됐다 — 08-26 개명 뒤로 평가에서 파지가 무음이었다.
#   · ★압박 6종(굴곡압박 등)은 <b>일부러 뺐다</b>. 평가에서 압박은 자율이고(실측 09-02 규칙),
#     안 하고 되돌리면 생략·감점이다. "압박하세요"라고 말하면 수행 방법을 알려 주는 것이 된다.
#     그래서 Advanced·Evaluation의 'X압박.mp3'도 지웠다(무음). 되살리려면 git에서 꺼낸다.

# ── 시작 자세 ──
자세정렬|시작 자세를 정렬하세요.

# ── 동작1 굴곡·신전 (환자 측면) ──
시상면 파지|환자 측면에서 파지하세요.
굴곡|굴곡을 진단하세요.
신전|신전을 진단하세요.
시상면평가|굴곡·신전 결과를 기록하세요.

# ── 동작2 측굴 (환자 뒷면) ──
관상면 파지|환자 뒷면에서 파지하세요.
우측굴|우측굴을 진단하세요.
좌측굴|좌측굴을 진단하세요.
관상면평가|측굴 결과를 기록하세요.

# ── 동작3 회전 (환자 뒷면) ──
횡단면 파지|환자 뒷면에서 파지하세요.
우회전|우회전을 진단하세요.
좌회전|좌회전을 진단하세요.
횡단면평가|회전 결과를 기록하세요.
