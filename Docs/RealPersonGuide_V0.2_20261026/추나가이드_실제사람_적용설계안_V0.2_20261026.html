한 줄 결론 — 기존 시나리오와 통과 조건은 그대로 두고, 실제 사람의 기준점과 접촉 영역을 맞추는 방식이다.

추가 장비 없음기존 조건 유지시작 전 맞추기만 추가

읽는 법 — 파란 점은 등록할 기준의 개념 위치다. 오른쪽 준비창에서 맞추기를 시작하고 실제 사람에게 손을 얹는다.
구분이 제안에서 뜻하는 것
맞추는 것시작 기준 좌표, 접촉 영역의 위치와 필요한 체형 크기를 맞춘다.
유지하는 것기존 단계·지시문·통과 각도·거리·진행률 기준·유지시간을 그대로 사용한다.
사용자 조작[사람에게 맞추기] → 올바른 파지로 잠깐 유지 → 기존 실습 진행이다.
범위: 공간 기준의 어긋남을 줄이는 제안이다. 개인의 실제 움직임 범위가 기존 통과 조건에 못 미치는 문제까지 기준점 보정으로 해결되지는 않는다.

사용자는 무엇을 누르나

맞추기를 누르고, 손을 얹고, 잠깐 유지한다

읽는 법 — 왼쪽에서 오른쪽으로 읽는다. 별도의 끝자세 지정이나 각도 입력 없이 기존 실습으로 이어진다.

기준점을 잡는 과정

1. 먼저 준비
손이 자유로울 때 [사람에게 맞추기]를 누른다.
2. 올바른 파지
그 술기에 필요한 시작 자리에 손을 얹는다. 위치는 지도자가 확인한다.
3. 손을 잠깐 유지
안정된 자세를 모으고 저장 표시·소리를 준다. 이후 기존 실습을 시작한다.

등록을 끝내기 위해 손을 떼고 버튼을 누를 필요가 없게 한다. 맞추기를 시작한 동안에만 저장하여 대기 중 잘못 등록되는 일을 줄인다.

등록 항목역할
손 기준 위치·방향기존 판정이 실제로 읽는 손 위치 신호와 같은 기준으로 저장한다. 그림 속 점은 개념 표시다.
접촉 위치·간격그 사람에게 올바르게 손을 얹은 자리에 접촉 영역을 배치하는 기준으로 사용한다.
환자 기준 좌표술기에 필요한 기준 좌표·피벗·방향축의 정렬에 연결한다. 손 두 점만으로 모든 축이 정해진다고 가정하지 않는다.
맞는 자리는 사람이 확인한다. 손을 얹은 곳을 저장하는 기능이며 신체 표면이나 해부학적 위치를 자동으로 인식하는 기능은 아니다. 기존 판정에 필요한 기준이 더 있으면 해당 술기에서 따로 확인한다.
다시 맞출 때: 사람·시작 자세·파지가 바뀌면 [다시 맞추기]로 필요한 기준을 등록한다. 보정값은 해당 세션에 사용하며 기존 시나리오 파일을 덮어쓰지 않는다.

거리와 충돌체를 어떻게 바꾸나

접촉 영역을 실제 사람의 자리에 맞춘다

읽는 법 — 회색은 기존 가상환자 배치, 초록은 실제 사람에게 맞춘 접촉 영역이다. 기존 접촉 판정 방식을 유지하고 영역의 배치를 맞추는 개념이다.
보정 항목구체적인 처리
위치·간격올바른 파지에서 등록한 자리로 영역을 배치한다. 전체 가상환자 크기를 일괄 변경하지 않는다.
영역 크기기존 판정이 쓰는 형태와 술기별 기본 크기를 출발점으로 삼는다. 실제 부위를 덮는지 확인해 필요한 크기만 맞춘다.
간단한 크기 확인기본 크기로 맞으면 그대로 시작한다. 필요할 때만 [좁게 / 보통 / 넓게]로 크기를 확인·조절한다.
판정 기준양손 접촉 등 기존 조건 조합을 유지한다. 잘 안 통과한다는 이유로 영역이나 허용오차를 계속 확대하지 않는다.
영역과 손을 같은 대상으로 만들지 않는다. 움직이는 손에 영역을 계속 붙여 접촉으로 인정하면 판정이 무의미해진다. 환자 부위가 움직이는 동안 기존 영역을 어떻게 따라가게 할지는 술기별 검증 대상이며, 접촉 이탈 조건을 임의로 없애지 않는다.

실습 중 화면은 얼마나 달라지나

맞춘 뒤에는 기존 시나리오를 그대로 진행한다

읽는 법 — 진행률·유지 게이지·단계 전환은 기존 시나리오 기준이다. 맞추기와 다시 맞추기만 추가하는 개념 화면이다.
유지하는 요소문서의 구현 방향
시나리오·안내기존 단계 순서·단계명·조건 종류·지시문·나레이션을 그대로 사용한다.
통과 조건기존 각도·거리 기준, 진행률 임계값, 유지시간과 접촉 조건 조합을 바꾸지 않는다.
UI·진행 방식기존 표시 의미와 자동 전환을 유지한다. 개인별 끝자세를 새로 지정하거나 진행률의 끝을 다시 정하지 않는다.
추가 조작은 보정에만 둔다. 기존 실습에서 매 동작마다 별도 완료 버튼을 누르게 하지 않는다. 재보정 때는 판정을 멈추고 해당 동작의 시작 기준을 다시 잡아 이어 붙임 오류를 줄인다.

구현 범위와 확인할 것

조건을 바꾸지 않고, 공간 기준을 맞추는 안이다

읽는 법 — 초록 상자가 새 보정 부분이다. 기존 시나리오와 통과 판단은 유지하고 앞단의 공간 기준을 맞춘다.
요소판단
구현할 부분맞추기 준비창, 기존 판정과 같은 손 신호의 등록, 환자 기준·접촉 영역의 세션 보정값 연결이다.
그대로 둘 부분CSV·Config의 기존 단계와 통과 기준, 진행률 산정의 기준량, 접촉 게이트와 유지 로직, UI 의미이다.
실제 사람에서 확인동일 파지의 등록 반복성, 기준점·접촉 영역의 정렬, 동작 중 접촉 판정과 진행률을 확인한다.
검증이 필요한 한계손 두 점만으로 전신 축·모든 피벗·녹화 궤적이 정확히 맞는지는 확인되지 않았다. 실제 움직임 범위 부족은 기준점 보정과 별개이다.
기존 조건으로 통과하지 못하는 경우: 기준 배치의 오류인지, 실제 수행 범위가 기존 조건에 못 미치는지 구분한다. 이번 안에서는 통과 조건을 낮추거나 수동 통과로 대신하지 않는다.
