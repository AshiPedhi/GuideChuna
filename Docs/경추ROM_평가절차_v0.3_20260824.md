# 경추 ROM 평가 절차 (앱 적용본)

**근거 문서** 경추 가동 범위(ROM) 임상 평가 표준 지침서 v0.2 (2026-08-22)
**작성** 2026-08-24 · 지침서 §3(굴곡·신전)의 단계 분해를 6방향 전체에 적용

---

## 0. 적용 원칙

지침서 §2의 **ROM 4단계**(자세·파지 → 능동 → 수동압박 → 평가)를 한 면(plane)마다 6단계로 편다.

```
파지 → 능동A → A압박 → 능동B → B압박 → 평가
```

앱 적용 시 지침서 원문에서 세 가지를 조정한다.

| # | 지침서 원문 | 앱 적용 | 이유 |
|---|---|---|---|
| 1 | 굴곡·신전은 이마+뒤통수 파지 | **전 과정 양손 측두부 유지** | 파지를 바꾸면 측정 중 축이 흔들린다. 시술자 지시 |
| 2 | 회전 시 한 손으로 견봉을 눌러 체간 고정 | **주의사항 안내만**, 손은 측두부 유지 | 양손이 머리에 있어야 회전축이 유지된다 |
| 3 | 능동 끝점에서 수동 압박 | **단계로 분리**해 명시 | 기존 CSV는 압박 문구가 복귀 동작에 얹혀 있었다 |

**정상 기준** 굴곡 45° · 신전 90° · 측굴 좌우 각 45° · 회전 좌우 각 90°
**산출물** 방향별 측정각이 아니라 **정상각 − 측정각 = 부족한 각도**. 좌우 비대칭 여부를 함께 본다.

## 2. ROM1 · 시상면 (굴곡 / 신전)

환자를 의자에 앉히고 시술자는 환자의 **옆쪽**에 선다.

| 스텝 | 단계 | 지시문 | 동작 |
|---|---|---|---|
| 1.1 | **파지** | 환자 옆쪽에 서서 양손으로 양쪽 측두부를 감싸 잡으세요. 측정이 끝날 때까지 이 파지를 유지합니다. | 안내 |
| 1.2 | | 양손을 측두부에 댄 채로 유지하세요. | 양손 접촉 3초 |
| 2.1 | **굴곡** | 파지를 유지한 채 목을 앞으로 굽히게 하세요. 정상은 45도입니다. | 안내 |
| 2.2 | | 손은 머리를 따라만 갑니다. 턱이 가슴에 얼마나 가까워지는지 보세요. | `ROM 굴곡` |
| 3.1 | **굴곡압박** | 환자가 더 못 굽히는 지점에서 조금 더 굽혀 보세요. 저항이 단단한지, 물렁한지, 튕기는지 확인합니다. | 양손 접촉 유지 |
| 3.2 | | 끝 느낌을 확인했으면 중립으로 돌아옵니다. | `ROM 굴곡 중립` |
| 4.1 | **신전** | 파지를 유지한 채 고개를 젖혀 하늘을 보게 하세요. 얼굴이 천장과 평행하면 정상(90도)입니다. | 안내 |
| 4.2 | | 손은 머리를 따라만 갑니다. 얼굴과 천장이 평행이 되는지 보세요. | `ROM 신전` |
| 5.1 | **신전압박** | 능동 끝 지점에서 조금 더 젖혀 보세요. 천장과 평행해지기까지 얼마나 남았는지 확인합니다. | 양손 접촉 유지 |
| 5.2 | | 끝 느낌을 확인했으면 중립으로 돌아옵니다. | `ROM 신전 중립` |
| 6.1 | **평가** | 굴곡 45도, 신전 90도를 기준으로 부족한 각도를 확인하세요. | 안내 |

> **시각 지표** 굴곡은 하악과 흉골의 근접도, 신전은 얼굴과 천장의 평행 상태로 판단한다.

## 6. 구현 메모

**CSV 행수** 33행 (기존 교육 20행 → 33행). 나레이션 신규 18개.

**압박 단계에 재생할 클립이 없다.** 현재 애니는 방향 6 + 중립 6 + 대기 = 13개뿐이고 압박 구간이 없다.
→ 파지 단계와 같은 방식으로 성립시킨다: `conditionType=PassiveStretch` · `conditionParams=bothHands` · **클립 비움** · `duration=3`.
게이트가 닫히면 시간이 안 쌓이므로 "양손을 댄 채 3초 유지"가 곧 압박 단계가 된다. 환자 모델에 추가 움직임은 안 보인다.
→ 실제 압박 움직임까지 보이려면 **방향별 압박 클립 6개**를 새로 만들어 `patientAnimationClip`만 채우면 이 구조 그대로 교체된다.

**각도는 판정에 쓰이지 않는다.** 교육 모드의 적정범위는 각도가 아니라 애니메이션 진행률(0.3~0.5)이고 `phaseOverrides`는 비어 있다. 문구의 45도·90도는 안내 텍스트일 뿐이다.
→ "45도 도달 여부"를 실제로 판정하려면 클립 끝이 정상각과 일치하는지 먼저 확인해야 한다.

**부족한 각도 · 좌우 비교는 아직 산출 경로가 없다.** 6·12·18의 평가 단계는 현재 안내 문구만이다. 결과 화면 스펙(방향별 측정각/정상각/부족각, 좌우차, Pre/Post)은 별도 작업이다.

**미확정** 굴곡·신전 파지를 지침서 원문대로 이마+뒤통수로 되돌릴 경우 1.1 문구만 교체하면 된다.
