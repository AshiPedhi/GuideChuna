## 아키텍처 요약

- **단일 TrainingScene 유지** — 기존 환자 모델·핸드·카메라·시나리오 엔진 그대로 재사용.
- 두경부 전용 오브젝트는 **`CranialRig` 그룹**(루트 = `CranialAdjustmentController`)으로 묶음.
- **★ `CranialRig`를 머리(skullTarget)의 자식으로 둔다** — 토글 단위(=`gameObject.SetActive`)이면서 동시에 머리를 따라 이동해야 하므로. (씬 루트에 두면 머리 움직임을 못 따라감 → 파지 트리거 위치가 머리에서 어긋남)
- **양방향 cross-talk 토글 (둘 다 필수)**:
  - **비두경부 → cranial OFF**: `ScenarioManager`가 cranial 조건 없으면 `CranialRig` 비활성 → grip 트리거 콜라이더 꺼짐.
  - **두경부 → 기존 머리 콜라이더 OFF**: `ScenarioManager.nonCranialHeadColliders`에 연결된 기존 머리 판정 콜라이더를 두경부 시 비활성 → 두경부 시술 중 기존 손접촉 감지기 오발동 방지. (비두경부 시 자동 재활성)
- substep 3개 구조: ① 파지(`cranialGrip`) → ②a 압력·방향(`cranialPressure`) → ②b 호흡(`cranialDepthBreath`).
  (임상 3단계[힘의 방향+자세 안정화]와 4단계[호흡 동기화]를 분리. ②a에서 영점 저장+적정존 유지, ②b에서 호흡 3회.)

```
TrainingScene (기존 그대로)
├─ skullTarget (머리, 기존)  ← 항상 active
│  ├─ [기존 머리 판정 Collider]  ← ScenarioManager.nonCranialHeadColliders에 연결 (두경부 시 자동 OFF)
│  ├─ CranialRig  ← ★ CranialAdjustmentController 부착 (토글 단위 = SetActive, 머리 자식이라 머리 따라 이동)
│  │  ├─ 후두 GripPointTarget (isTrigger 콜라이더)
│  │  ├─ 측두 GripPointTarget (isTrigger 콜라이더)
│  │  ├─ DepthPressureGuide ×2 (arrowVisual)
│  │  ├─ directionObject ×2 (forward = 정답방향, 머리 따라 회전)
│  │  ├─ CranialRhythmIndicator (진단/재평가 리듬 시각화)
│  │  ├─ 좌측 OM 지표 (leftIndicator)   ← 시작 시 비활성 (rig OnEnable이 토글)
│  │  └─ 우측 OM 지표 (rightIndicator)  ← 비대칭 모드에서 진폭 축소(제한측)
└─ MainCamera (기존)
   └─ BreathingSyncHUD (World Space Canvas, 카메라 자식)  ← ★ CranialRig 밖! 시작 시 비활성
      └─ (screenEdgeWarning UI도 여기 카메라 자식)
```
> ※ OM 지표·directionObject·grip 타겟을 모두 CranialRig(=머리 자식) 아래 두면 머리를 따라 움직이면서 토글도 함께 받는다. (지표는 콜라이더가 없어 cross-talk 무관하지만 머리 추종을 위해 같은 트리 권장)

> ⚠️ **BreathingSyncHUD / screenEdgeWarning 은 CranialRig 자식이 아니다.**
> 카메라 자식(스테레오 안정)으로 두되, `CranialAdjustmentController`가 **참조(SerializeField)로 교차 연결**한다.
> 컨트롤러가 `BeginGripPhase()`에서 HUD를 끄고 `StartBreathingWindow()`에서 켜므로, **씬 시작 시 HUD GameObject는 비활성**으로 둘 것. (CranialRig 토글과 독립)

## 1. 씬 오브젝트 구성 (순서대로)

> 아래 순서로 하면 와이어링(§2)이 위→아래로 자연스럽게 채워진다.

### 1-1. CranialRig 루트
- [ ] 빈 GameObject `CranialRig` 생성 (씬 루트 또는 환자 모델 옆)
- [ ] `CranialAdjustmentController` 부착 (이 컴포넌트가 붙은 GameObject = 토글 단위)
- [ ] **씬 시작 시 active 상태 무관** — `ScenarioManager`가 시나리오에 따라 자동 ON/OFF

### 1-2. 파지 타겟 ×2 (skullTarget 자식 권장)
| 대상 | 설정 | 비고 |
|---|---|---|
| [ ] 후두골 타겟 | `GripPointTarget` + Collider **isTrigger=true**, Rigidbody 없음 | 왼손 파지 지점 |
| [ ] 측두골 타겟 | `GripPointTarget` + Collider **isTrigger=true**, Rigidbody 없음 | 오른손 파지 지점 |

> 콜라이더 크기: 손끝이 "닿았다" 판정될 정도(반경 ~1.5~3cm Sphere 권장). 너무 작으면 진입 누락.
> 머리를 따라 움직이도록 **skullTarget(머리) 자식**으로 둘 것.

### 1-3. 손끝 콜라이더 ×2 (트리거 진입원) — ✅ Option B: 코드 자동생성 (수동 작업 없음)
- [x] **수동 부착 불필요**. `CranialAdjustmentController.autoCreateFingerColliders=true`(기본)이면, §2에서 라이브 `HandVisual` 좌/우를 연결하는 순간 런타임에 손끝 본 아래 자식 `CranialGripFingerCollider`(SphereCollider, isTrigger, 반경 `fingerColliderRadius` 기본 1.2cm)가 생성되어 좌/우 `GripPointTarget`에 자동 연결됨.
- [x] 깊이 `fingertip`과 **같은 손끝 본**을 자동으로 공유 → 영점·파지 손가락 자동 일치 (불일치 오차 없음).
- [ ] (Option A로 갈 경우만) `autoCreateFingerColliders=false`로 끄고, 손끝에 Collider 수동 부착 후 `GripPointTarget.expectedFingerCollider`에 직접 연결.

### 1-4. directionObject ×2 (정답 방향)
- [ ] 두개골 내부에 빈 오브젝트 2개, **각 오브젝트의 `forward(파란 축)` = 정답 압력 방향**
- [ ] 왼손 = 굴곡 / 오른손 = 하방·내방
- [ ] **skullTarget 자식**으로 둬 머리 회전 시 정답방향도 함께 회전
- [ ] forward 방향 검증: 임시 화살표 메시(또는 Gizmo)로 파란 축이 누르는 방향을 가리키는지 눈으로 확인

### 1-5. skullTarget
- [ ] 기존 두개골(머리) 모델 Transform 지정 — **영점·깊이·정답벡터의 로컬 프레임 기준** (월드 아님)

### 1-6. 호흡 HUD (카메라 자식)
- [ ] `BreathingSyncHUD` + **World Space Canvas**를 **메인카메라 자식**으로 배치 (Quest 스테레오 깨짐 방지)
- [ ] **씬 시작 시 GameObject 비활성**으로 둘 것 (컨트롤러가 substep②에서 활성화)

## 2. 컴포넌트 와이어링 (SerializeField 연결)

> 필드명은 실제 코드 기준(2026-06-25 검증). 괄호 = 코드 기본값.

### GripPointTarget (후두/측두 타겟 각각)
- [x] `expectedFingerCollider` ← **Option B로 코드가 런타임 자동 연결**(컨트롤러가 HandVisual에서 생성한 손끝 트리거 콜라이더). 인스펙터 수동 연결 불필요.
- [ ] (Option A 시만) `expectedFingerCollider` 수동 연결 또는 `expectedFingerTag` 태그 식별
- [ ] (테스트용) `bypassPoseCheck = true` — M1 전까지 트리거만으로 파지 성립
- [ ] (선택) `targetRenderer`(파지 시 색 전환) / `idleColor`(흰 0.3) / `grippedColor`(green)
- [ ] (선택) `audioSource` + `clickSound`(파지 성립 찰칵)

### DepthPressureGuide (왼손/오른손 각각 1개)
- [ ] `skullTarget` ← 머리 Transform **(필수)**
- [ ] `directionObject` ← 해당 손 정답방향 오브젝트 **(필수)**
- [ ] `fingertip` ← 손끝 Transform **(필수)** — ⚠️ 아래 "fingertip 주입" 참고
- [ ] 깊이 임계값(m): `goodMin`(0.005) / `goodMax`(0.015) / `overThreshold`(0.020) / `maxAngle`(45°)
- [ ] 손떨림 보정: `lerpSpeed`(10) / `deadzone`(0.001=1mm)
- [ ] (선택) `arrowVisual`(Shake 대상) / `arrowRenderer`(색단계) / `screenEdgeWarning`(방향오류 경고) / `shakeMagnitude`(0.003)
- [ ] (선택) `audioSource` + `goodSound` / `errorSound`

> **⚠️ fingertip 주입 함정**: Oculus 핸드 조인트 Transform이 **런타임 생성**이면 인스펙터로 미리 연결 불가.
> 이 경우 손이 준비된 뒤 `depthGuide.SetFingertip(jointTransform)` (또는 `SetSkullTarget`)으로 **코드 주입**해야 한다.
> 조인트가 씬에 상시 존재(프리팹 고정)하면 인스펙터 연결로 충분. → §0에서 손 리그 확인 후 방식 결정.
> `fingertip`/`skullTarget`/`directionObject` 중 하나라도 null이면 `Update`가 **조용히 return**(깊이 미작동)하고, `SaveZeroPoint`는 경고 로그만 남기고 영점 저장 실패하니 콘솔 확인.

### BreathingSyncHUD (카메라 자식, 시작 시 비활성)
- [ ] `breatheInDuration`(4) / `breatheOutDuration`(4) / `requiredBreaths`(3) / `requiredHoldRatio`(0.7)
- [ ] (선택) `ringVisual`(scale 팽창/수축) `ringMinScale`(0.5)/`ringMaxScale`(1) **또는** `fillImage`(fillAmount)
- [ ] tensionProvider는 코드에서 자동 주입됨(컨트롤러 `StartBreathingWindow` = 양손 모두 goodZone) — 수동 연결 불필요

### CranialRhythmIndicator (CranialRig, 진단/재평가 리듬 시각화)
- [ ] `leftIndicator` ← 좌측 OM 지표 Transform (정상측), `rightIndicator` ← 우측 OM 지표 (제한측)
- [ ] 지표 오브젝트 2개는 **skullTarget(머리) 자식 + 씬 시작 시 비활성**으로 둘 것 (rig OnEnable/OnDisable이 토글)
- [ ] 리듬 튜닝: `cyclesPerMinute`(9, 정상 6~12) / `flexAxis`(굴곡 변위 축) / `amplitude`(0.004m) / `restrictedRatio`(0.2=제한측 진폭)
- [ ] (선택) `leftRenderer`/`rightRenderer` + `normalColor`(green)/`restrictedColor`(주황)
- 모드는 컨트롤러가 자동 구동: **호흡 완료 전=비대칭(좌 정상/우 제한) → 완료 후=대칭** (수동 연결 불필요)

### CranialAdjustmentController (CranialRig 루트)
- [ ] `leftGrip` / `rightGrip` ← GripPointTarget 2개 (왼손=후두, 오른손=측두)
- [ ] `leftDepth` / `rightDepth` ← DepthPressureGuide 2개
- [ ] `breathingHUD` ← BreathingSyncHUD (**카메라 자식이라도 참조 교차 연결 OK**)
- [ ] `rhythmIndicator` ← CranialRhythmIndicator (선택 — 진단/재평가 리듬 시각화)
- [ ] **`leftHandVisual` / `rightHandVisual` ← 라이브 player HandVisual (왼손/오른손)** — ChunaLimitChecker가 참조하는 그 라이브 추적 손. ⚠️ HandTransformMapper에 캡처된 녹화/재생용 손(enabled=false) 연결 금지(깊이 고정됨, 컨트롤러가 경고 로그 출력). 이 둘만 연결하면 손끝(깊이)+파지 콜라이더(Option B) 자동.
- [ ] (Option B) `autoCreateFingerColliders = true`(기본) / `fingerColliderRadius`(0.012m) — 파지 트리거 콜라이더 자동생성. Option A면 false.
- [ ] (선택) `fingertipJoint`(기본 HandIndexTip, 미보급 SDK는 HandIndex3 자동 폴백)
- [ ] `drivePoseFromComparator = false` (M1 후 true)

### ScenarioManager
- [ ] `cranialController` 연결 — 비우면 `FindFirstObjectByType<CranialAdjustmentController>(Include inactive)`로 **자동 탐색**되나 명시 권장
- [ ] `nonCranialHeadColliders` ← **기존 머리 판정 콜라이더**(머리 본체에 부착된 비두경부 손접촉 감지용, 예: `PatientHeadTouchDetector`/`PokeDetector`의 Collider) 연결
  - ⚠️ **반대방향 cross-talk 차단용**: 두경부 시나리오일 때 이 콜라이더들을 자동 비활성화 → 두경부 시술 중 시술자 손이 머리에 닿아도 기존 감지기가 오발동 안 함. 비두경부 시나리오에선 자동 재활성.
  - 비우면 기존 머리 콜라이더가 두경부 시술 중에도 살아있어 **간섭 위험** → 머리에 손접촉 판정 콜라이더가 있으면 **반드시 연결**.

## 3. CSV 데이터 (`두개골교정.csv` — ✅ 표준 아크로 생성됨)

표준 교육 아크(시작 → 평가 → 교정 → 재평가 → 종료)로 구성. **핵심 술기 2 substep만 대화형**, 평가/재평가는 `duration` 타이머 단계(에셋 불필요).

| phase | step | conditionType(자동/명시) | 완료 방식 |
|---|---|---|---|
| 시작 | 가이드 | Manual(자동) | [시작] 버튼 |
| 평가 | 진단 ×3 (초기위치/리듬관찰/장애판별) | Duration(자동, dur 8/12/8) | 타이머 자동 진행 |
| 교정 | **파지** | **`cranialGrip`(명시)** | 양손 파지 게이트 |
| 교정 | **압력방향** | **`cranialPressure`(명시)** | 영점저장 → 양손 적정존 유지 |
| 교정 | **호흡동기화** | **`cranialDepthBreath`(명시)** | 호흡 3회 (영점 유지) |
| 재평가 | 재평가 | Duration(자동, dur 10) | 타이머 자동 진행 |
| 종료 | 가이드 | Manual(자동) | [메인] 버튼 |

- [ ] 나레이션 **자리표시자 문구 임상 검수** (`textInstruction`) — 특히 평가/제한확인/재평가 내용
- [ ] 평가/재평가를 타이머 대신 음성/버튼으로 바꿀지 결정 (현재 `duration` 타이머)
- [ ] 음성 클립 쓰면 `voiceInstruction`에 클립명 추가 (현재 전부 비어 있음 → 무음 진행)
- [ ] (선택) 평가 단계에 실제 진단 동작/애니메이션이 필요하면 `patientAnimationClip`/`movementType`/영상 타임코드 추가 (현재 미사용 — 해당 에셋 없으면 비워 둘 것)

> ⚠️ **근육 MET 시나리오를 복붙하지 않은 이유**: 근육 시나리오의 진단/등척성/스트레칭 단계는 환자 사지 **애니메이션 클립 + 영상 타임코드** 에셋에 의존. 두개골 교정엔 해당 에셋이 없어, 지어내면 깨진 시나리오가 됨. 평가/재평가는 에셋 불필요한 `duration` 단계로 대체.
> ⚠️ conditionType 문자열은 **대소문자 정확히** `cranialGrip` / `cranialDepthBreath` (코드가 OrdinalIgnoreCase 비교).
> 이 conditionType이 CranialRig 자동 토글(`ScenarioHasCranialCondition`)의 트리거도 겸함.
> `handTrackingFileName`/`contactTarget`은 **비워 둘 것** — cranial은 자체 `GripPointTarget` 콜라이더 사용, 기존 접촉감지와 cross-talk 방지.

## 3-A. Play 모드 단계별 검증 (bypassPoseCheck 상태에서)

> 씬·CSV 연결 후 M1 이전에 **트리거·깊이·호흡 로직을 먼저 검증**하는 순서.

1. **CranialRig 자동 토글**
   - [ ] `두개골교정` 시나리오 시작 → CranialRig **활성화** 로그/상태 확인
   - [ ] 비두경부 시나리오(예: 사각근) 시작 → CranialRig **비활성** 확인 (머리 트리거 cross-talk 없음)
1-b. **두개골 리듬 (평가 phase)**
   - [ ] 진단 단계에서 좌/우 OM 지표가 리듬으로 진동 — **좌측 정상 진폭 / 우측 제한**(restrictedRatio) = 비대칭
   - [ ] 우측 지표 색 = 제한(주황), 좌측 = 정상(green) (Renderer 연결 시)
   - [ ] (교정 후) 재평가 단계에서 **양측 동일 진폭 = 대칭** + 양측 정상색 → 호흡 완료가 모드 전환 트리거
   - [ ] 비두경부 시나리오 / 종료 후 지표 비활성(숨김) 확인
2. **파지 (substep①)**
   - [ ] 양손 손끝을 후두/측두 타겟에 진입 → 각 타겟 색 전환 + 찰칵, `[GripPointTarget] 파지 성립` 로그
   - [ ] 양손 모두 파지 시 substep① 완료 → 완료피드백 + 다음 substep 진행
3. **압력·방향 (substep ②a `cranialPressure`)**
   - [ ] 진입(첫 폴) 시 `[DepthPressureGuide] 영점 저장(로컬)` 로그 2회(양손) — 휴식 위치 = 깊이 0
   - [ ] 손끝을 정답방향으로 천천히 밀기 → arrow가 idle→green(0.5~1.5cm)→red+Shake(2.0cm+)
   - [ ] 뒤로 당기거나(음수) 45° 이상 빗나가면 → `WrongDirection`(red + screenEdgeWarning)
   - [ ] **양손 모두 goodZone을 ~1초 유지**하면 substep ②a 완료 (`PressureCondition` holdDuration 기본 1.0s)
4. **호흡 (substep ②b `cranialDepthBreath`)**
   - [ ] 진입(첫 폴) 시 호흡 윈도우 시작 — **영점 재저장 안 함**(②a 영점 유지, 압력 연속성)
   - [ ] HUD 링 팽창(들숨)/수축(날숨) 4초 주기
   - [ ] 들숨 구간 양손 goodZone 유지 시 `호흡 성공 n/3` 로그, 3회 성공 시 substep ②b 완료
   - [ ] 유지비율 0.7 미만이면 `호흡 실패 - 카운트 리셋` (연속 카운트 초기화)

> 검증 중 깊이가 전혀 안 움직이면: `fingertip`/`skullTarget`/`directionObject` null 여부 콘솔 확인(§2 함정).
> ②a가 완료 안 되면: 양손이 **동시에** goodZone(0.5~1.5cm)을 1초간 유지해야 함. 한 손만 또는 과압(2cm+)이면 미충족.
> ②b 호흡이 시작 안 되면: 진입 순간 **양손 파지 유지**가 안 됐을 수 있음(`BreathingCondition`은 영점 없으면 파지 유지 시 lazy 저장 후 시작).
> ②a holdDuration(1.0s)은 `PressureCondition` 생성자 인자 — 더 길게 요구하려면 `ScenarioManager.HandleCranial`에서 `new PressureCondition(ctrl, 2.0f)` 식으로 조정.

## 결정/근거 기록 (참고)
- **깊이 좌표계 = 두개골 로컬** (월드 아님). 머리가 살짝 흔들리거나 위로 들려도 깊이 오판 방지. 영점/정답벡터 모두 `skullTarget` 로컬 프레임.
- **깊이 = `Vector3.Dot(moveLocal, dirLocal)`** (순수 유효 깊이), 방향오류 = `dot<0 || Vector3.Angle > maxAngle`.
- **손떨림 보정** = Deadzone(raw, 1mm) → `Mathf.Lerp`(시각).
- **호흡 판정** = 들숨 구간 적정 텐션 유지비율 ≥ 0.7, 3회 연속.
- **substep 구조 C** = 파지 / 압력+호흡 (기능2·3은 동시 진행이라 한 substep).
- **통합 방식** = `ScenarioConditionManager`의 등록조건 폴링 레일 재사용(나레이션/완료피드백/20초 힌트/NextSubStep 공짜). switch 무수정, 등록만 추가.
