# 경추 ROM 진찰 절차 (앱 적용본) v0.4

**근거 문서**
- 경추부 ROM 진찰 교육자료 **ver0.5** (2026-08-22, pptx 15장) — **정본**
- 경추 가동 범위(ROM) 임상 평가 표준 지침서 v0.2 (2026-08-22, 감수 코멘트 7건 달린 초안)

**적용 결과** `경추ROM측정.csv` **51행** (교육 40 · 실측 9 · 시작·종료 2), 교육 나레이션 21개
v0.3에서 바뀐 것: 진찰 전 준비 3단계 신설, 시술자 위치 명시, 관찰 포인트 추가, 문구 정정

---

## 0. 구조

교육자료의 **ROM 4단계**(자세·파지 → 능동 → 수동압박 → 평가)를 3개 동작에 적용한다.
교육자료 슬라이드 7·9·11의 "실제 수행"이 이미 6칸으로 펴져 있고, 앱은 그 순서를 그대로 따른다.

```
진찰 전 준비 → 동작1 시상면 → 동작2 관상면 → 동작3 횡단면
                (6단계)        (6단계)        (6단계)
```

## 1. 원문에서 조정한 것

| # | 교육자료 v0.5 | 앱 적용 | 근거 |
|---|---|---|---|
| 1 | 굴곡·신전은 엄지·검지로 **이마와 뒤통수** 파지 | **그대로 반영** | 교육자료·지침서 일치 |
| 2 | 회전 시 **한 손으로 견봉·쇄골을 눌러** 몸통 회전 차단 | **주의사항 안내만**, 손은 측두부 유지 | 양손이 머리에 있어야 회전축이 유지된다. 사용자 지시(08-24 2회) |
| 3 | 시술자 위치 (시상면=우측 측면 / 관상면·횡단면=후면) | **그대로 반영** | 시상면 각도는 옆에서 봐야 보인다 |

★ **2번만 교육자료와 다르다.** 자료를 그대로 쓰는 실습 지도와 앱 절차가 이 한 지점에서 갈린다.

**파지 정리** — 동작1은 **이마+뒤통수**, 동작2에서 **측두부로 교체**하고 동작3까지 유지한다. 교체는 10.1(관상면 파지) 단계에서 일어난다.

## 2. 진찰 전 준비 (교육자료 슬라이드 5)

| 스텝 | 단계 | 지시문 |
|---|---|---|
| 1.1 | **문진** | 외상력이 있는지, 어지럼이나 저림 같은 증상이 있는지 먼저 물으세요. |
| 2.1 | **설명·동의** | 평가의 목적과 중단 신호를 알리고 동의를 받으세요. 통증이 급격히 커지거나 어지럼·저림이 나타나면 즉시 멈춥니다. |
| 3.1 | **자세 정렬** | 환자를 의자에 앉히고 몸통과 어깨를 정면으로 맞추세요. |

## 3. 동작1 · 시상면 (굴곡 45° / 신전 90°)

시술자는 환자의 **우측 측면**에 선다.

| 스텝 | 단계 | 내용 | 동작 |
|---|---|---|---|
| 4.1 | 파지 | 우측 측면에 서서 **엄지와 검지로 이마와 뒤통수**를 감싸 쥔다 | 안내 |
| 4.2 | | 힘으로 누르지 말고 축만 지지한다 | 양손 접촉 3초 |
| 5.1 | 굴곡 | 최대한 앞으로 굽히게 한다. 정상 45° | 안내 |
| 5.2 | | 하악–흉골 근접도 · **흉추/몸통 보상, 턱의 전방 이동** 관찰 | `ROM 굴곡` |
| 6.1 | 굴곡압박 | 끝 지점에서 힘을 더한다. Hard / Soft / Springy 판단 | 안내 |
| 6.2 | | 끝 느낌 확인 | 접촉 유지 3초 |
| 6.3 | | 중립 복귀 | `ROM 굴곡 중립` |
| 7.1 | 신전 | 하늘을 보게 한다. **얼굴 정면과 천장의 평행** = 90° | 안내 |
| 7.2 | | 평행 여부 관찰 | `ROM 신전` |

## 4. 동작2 · 관상면 (좌·우 측굴 각 45°)

시술자는 **후면(배측)**으로 이동한다.

| 스텝 | 단계 | 내용 | 동작 |
|---|---|---|---|
| 10.1 | 파지 | 후면으로 이동. **파지를 측두부로 교체** (엄지·검지로 양 측면 받침) | 안내 |
| 11.1 | 우측굴 | **"얼굴은 정면을 유지한 채"** 오른쪽 귀가 어깨로 | 안내 |

| 12.1~3 | 우측굴압박 | 압박 → 끝느낌 → 복귀. **좌우 세기·시간을 같게** | 3행 |

## 6. 결과 화면 스펙 (교육자료 슬라이드 13)

기록 서식이 확정됐다. 6행 고정.

| 동작 | 측정 항목 | 정상 | 시술 전(Pre) | 부족한 각도 | 시술 후(Post) | 끝느낌·특이사항 |
|---|---|---|---|---|---|---|
| 동작1 | 굴곡 | 45° | | | | |
| 동작1 | 신전 | 90° | | | | |
| 동작2 | 좌 측굴 | 45° | | | | |

| 동작3 | 좌 회전 | 90° | | | | |

끝느낌은 **Hard / Soft / Springy** 3지선다. 물성 재현은 VR에서 불가하므로 입력만 받는다.
해석 4문: ①어느 방향이 제한되는가 ②통증과 저항 중 무엇이 멈추게 했는가 ③좌우 차이가 일관적인가 ④주 증상과 연결되는가

## 7. 구현 메모

**압박 단계에 재생할 클립이 없다.** 애니는 방향 6 + 중립 6 + 대기 = 13개뿐이다.
→ 파지와 같은 방식으로 성립시켰다: `PassiveStretch` + `bothHands` + **클립 비움** + `duration=3`.
게이트가 닫히면 시간이 안 쌓이므로 "양손 댄 채 3초"가 압박 단계가 된다. **환자에 추가 움직임은 안 보인다.**
→ 방향별 압박 클립 6개를 만들면 `patientAnimationClip`만 채워 그대로 교체된다.

**`PassiveStretch` 행에는 `voiceInstruction`을 넣지 않는다.** 나레이션이 접촉 게이트를 죽인다. 지시(voice)와 동작(condition)을 다른 substep으로 쪼갠 이유다.

**각도는 판정에 쓰이지 않는다.** 교육 모드 적정범위는 애니 진행률(0.3~0.5)이고 `phaseOverrides`는 비어 있다. 45°/90°는 안내 텍스트일 뿐이다.

**Pre/Post 비교가 아직 없다.** 교육자료의 뼈대인데 세션 저장 구조가 없다. 실측 모드의 `재측정`은 기준점 재확인 수준이다.

**미해결** 상급·평가는 `stepName` 클립만 보는데 stepName이 바뀌어 25개가 무음이다. 평가모드는 '수행 방법 미고지' 원칙이라 문구를 따로 써야 하므로 자동 생성하지 않았다.

**버전 불일치** 교육자료 표지는 "지침서 v0.5 기준"인데 발표자 노트는 "v0.3 기반"이고, 실제로 받은 지침서는 v0.2다. 지침서 v0.5가 따로 있으면 대조가 필요하다.
