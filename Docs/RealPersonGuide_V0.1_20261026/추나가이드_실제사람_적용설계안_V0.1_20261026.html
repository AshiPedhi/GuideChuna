추나 가이드, 어떻게 맞출까

2026-10-26 · GuideChuna · 코드 정적 확인에 근거한 구현 제안

한 줄 결론 — 기존 화면과 자동 진행을 활용하되, 시작 파지를 등록하고 개인별 자동 진행에는 목표도 등록하는 방식이다.

추가 장비 없음기존 흐름 재사용시작 전 조작에 집중

읽는 법 — 파란 점은 등록할 손 자리다. 오른쪽 창만 시작 전에 추가하는 개념이다. 사람과 손은 설명용으로 단순화했다.
구분이 제안에서 뜻하는 것
보정맞다고 확인한 시작 파지와 손 움직임 기준을 저장한다.
유지기존 단계·UI 틀·진행률·유지 후 자동 전환을 재사용한다.
한계손 추적만으로 환자 표면·관절각·안전 범위를 직접 알지는 못한다.
범위: 보정 한 번으로 모든 술기가 그대로 동작한다는 제안은 아니다. 손에서 판단 가능한 술기부터 적용한다.

사용자는 무엇을 누르나

시작 전 작은 준비창 하나로 모은다

읽는 법 — 왼쪽에서 오른쪽으로 읽는다. 노란 목표 등록은 개인별 통과 목표가 필요한 동작에만 추가한다.

시작 파지는 이렇게 등록한다

1. 먼저 준비
손이 자유로울 때 [사람에게 맞추기]를 누른다.
2. 올바른 자리
실제 사람에게 필요한 파지를 한다. 시작 위치는 지도자가 확인한다.
3. 손을 잠깐 유지
준비된 상태에서 안정된 손 자세를 모으고 소리·표시로 저장을 알린다.

손을 얹은 뒤 버튼을 누르기 위해 다시 떼게 하지 않는다. 설명을 듣다가 손을 멈췄다는 이유로 임의 저장하지도 않는다.

목표 등록은 누구에게 필요한가

사용 상황필요한 준비
시작 파지 위치만 보정시작 등록으로 위치 차이를 줄인다. 개인별 목표 범위는 얻지 못한다.
개인별 목표로 자동 진행지도자가 정한 목표 손 자세를 추가 저장한다. 같은 사람·동작에서는 재사용한다.
사람·자세·파지 변경이전 기준을 무효로 하고 다시 등록한다. 임의 자동 추종으로 해결하지 않는다.
목표를 정하는 주체: 앱이 개인의 가능한 최대 범위를 찾아 주는 기능이 아니다. 지도자가 정한 목표를 앱에 기록한다.
조작 초안: 일상 화면은 기존대로 두고, 준비창의 [시작 맞추기]·[목표 등록]과 실습 중 [다시 맞추기]만 추가 후보로 둔다. 명칭과 배치는 논의 대상이다.

거리와 충돌체를 어떻게 바꾸나

몸 전체 대신 필요한 시작 접촉 영역을 맞춘다

읽는 법 — 회색은 기존 가상환자 기준, 초록은 등록한 시작 파지 기준이다. 위치 차이의 원리를 보여 주며 실제 오차 크기나 축척은 나타내지 않는다.
보정 항목구체적인 처리
위치·간격등록 순간의 각 손 기준점으로 중심을 정한다. 손 사이 간격은 그 사람의 파지 간격을 반영한다.
영역 크기손가락·손바닥 접촉 방식에 맞는 술기별 기본값을 쓴다. 손 사이가 넓다고 영역까지 크게 늘리지 않는다.
허용 여유접촉 허용 폭과 추적 흔들림 여유를 분리한다. 흔들린다는 이유로 계속 자동 확대하지 않는다.
사용자 조절평소에는 숨긴다. 필요할 때만 [좁게 / 보통 / 넓게]로 조절하는 안을 검토한다.
동작 중에는 별도 판단이 필요하다. 시작 영역은 시작 파지 확인용이다. 움직이는 손에 영역을 계속 붙여 “접촉”으로 인정하면 손이 언제나 자기 영역 안에 있게 된다. 피부 접촉의 지속 여부는 손 위치만으로 확정할 수 없다.

조건 통과 각도를 어떻게 보정하나

고정 각도 대신 등록 목표까지의 손 진행률을 쓴다

읽는 법 — 세 손 표시는 같은 동작의 출발·수행·목표를 뜻한다. 관절 위치나 실제 관절각을 나타내는 그림이 아니다.
시작 등록이 정하는 것

출발 손 위치·방향과 상대 움직임의 원점을 정한다.

이 정보만으로 개인별 통과 목표는 알 수 없다.

목표 등록이 정하는 것

지도자가 지정한 목표 손 자세를 저장해 자동 통과의 기준으로 쓴다.

안전 범위나 올바른 술기를 앱이 발견한 결과가 아니다.

기존 요소실제 사람 적용안
진행률선택한 손 신호를 시작에서 목표까지의 진행 정도로 바꿔 기존 흐름에 공급한다.
방향·유지방향 검사와 유지 조건은 관찰 가능한 항목을 골라 연결한다. 목표점에 닿았다는 이유만으로 전체 동작을 정답으로 보지는 않는다.
각도 표기손에서 구한 값을 실제 관절각으로 표시하지 않는다. 해당 항목은 [등록 목표 대비 진행률] 등으로 바꿔야 한다.
보조수 기준고정 역할을 하는 술기에서만 주동수의 상대 움직임 기준으로 검토한다. 양손이 함께 움직이는 동작에 일괄 적용하지 않는다.
간단함의 대가: 최초 목표 등록이 추가된다. 학습자가 혼자 한 동작을 자동으로 정답으로 삼는 방식은 기본안에서 제외한다.

실습 중 화면은 얼마나 달라지나

익숙한 진행 화면에 상태와 재보정만 더한다

읽는 법 — 진행 패널·유지 게이지·단계 전환 구조를 재사용하는 개념이다. 버튼 배치와 문구는 현재 화면을 그대로 복제한 것이 아니다.
상황화면과 진행 처리 제안
손 추적이 끊김상태를 알리고 판정을 잠시 멈춘다. 누적 유지시간의 처리 방식은 기존 로직을 확인해 정한다.
환자 자세·파지 변경[다시 맞추기]로 해당 동작의 준비 상태로 돌아간다. 기준이 바뀐 채로 진행률을 이어 붙이지 않는다.
목표가 등록되지 않음개인화 자동 통과 준비가 안 됐음을 표시한다. 임의 기본 각도로 조용히 대체하지 않는다.
기본안은 자동 진행이다. [완료]를 매 동작 누르는 흐름은 기본에 넣지 않는다. 손으로 판단할 수 없는 조건의 수동 처리 여부는 해당 술기 검토 후 별도로 결정한다.

구현 범위와 다음 논의

기존 시스템에 대상별 보정 입력을 연결한다

읽는 법 — 초록 상자가 새로 필요한 부분이다. 기존 자동 조건의 의미가 달라지는 항목은 연결 전에 분리해 확인한다.
요소판단
단계·UI·나레이션대부분 재사용 후보이다. 고정 각도·가상환자 전용 문구는 변경과 나레이션 재생성이 필요할 수 있다.
접촉·진행·점수보정 입력 연결이 필요하다. 시작 근접과 피부 접촉을 같은 것으로 채점하지 않는다. 기존 점수의 의미도 재검토한다.
가이드 손의 정확한 겹침시작 손 두 점만으로 전체 신체 좌표계·궤적 정렬을 보장할 수 없다. 별도 검증 항목으로 둔다.
첫 적용 대상보조수가 고정되고 주동수가 움직이는 동작을 후보로 좁힌다. 특정 술기는 아직 확정하지 않았다.
첫 구현 전에 함께 정할 것
① 처음 적용할 동작 ② 지도자가 목표를 등록하는 방식 ③ 기존 화면 중 반드시 유지할 표시
파일럿 확인: 시작 등록 반복성, 바른 동작·틀린 방향의 구별, 재보정 후 상태 초기화, 다른 공유 술기의 기존 동작을 확인한다.
