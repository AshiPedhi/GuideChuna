# Part 2. 프로그램 소개 (본문)

## 한 줄 정의

> **CoCoChuna는 Meta Quest VR에서 맨손으로 추나(현훈추나) 술기를 반복 훈련하고, 술기 정확도를 객관적으로 평가·기록하는 교육 프로그램입니다.**

## 왜 필요한가 — 기존 실습의 한계

추나 술기는 **손의 위치·파지·방향·리듬·호흡 동기화**가 몸에 배어야 하는 술기입니다. 그러나 전통적 실습은:

- 🧑‍🤝‍🧑 **모델 환자·강사**가 있어야만 연습 가능 → 시간·공간 제약
- 🔁 **반복 훈련이 어렵고**, 잘못된 습관을 스스로 발견하기 힘듦
- 📊 **평가가 주관적** → 학습자의 성취도를 객관적으로 관리하기 어려움

## 핵심 개념

CoCoChuna는 VR 공간의 **가상 환자**에게 술기를 수행하고, **손 트래킹**으로 손모양·위치·방향을 인식해 **가이드 시연과 비교·평가**합니다.

```
가상 환자 + 맨손 손 트래킹  →  가이드 손 시연 · 음성 나레이션으로 따라하기
                            →  손포즈 유사도 · 술기 한계 자동 채점
                            →  등급·점수·결과 기록 (기관/개인별 관리)
```

## 주요 기능

| 기능 | 내용 |
|------|------|
| 🖐 **맨손 술기 재현** | 컨트롤러 없이 손 트래킹으로 파지·접촉·방향을 그대로 재현 |
| 👻 **가이드 손 시연** | 정답 동작을 반투명 손으로 보여주고 따라하게 안내 |
| 🔊 **음성 나레이션** | 단계별 자연스러운 한국어 음성으로 술기 순서 안내 |
| 🎯 **자동 채점** | 손포즈 유사도(60) + 술기 한계 준수(40) → **S~F 등급** 산출 |
| 📚 **연습 / 평가 모드** | 연습은 가이드·무제한 반복, 평가는 공식 점수·기록 |
| ☁️ **결과 관리** | 개인/기관 단위로 점수·시도횟수 저장 및 서버 업로드 |
| 🧩 **데이터 드리븐 확장** | 새 술기를 데이터만 추가해 빠르게 확장 (단일 통합 씬 구조) |
| 🏫 **키오스크 운용** | 부팅 시 자동 실행, 교육기관 상시 배치에 적합 |

## 훈련 콘텐츠 — 제공 술기 (13종)

| 분류 | 술기 |
|------|------|
| **경근(근육) 이완** | 상부승모근 · 견갑거근 · 대흉근 · 흉쇄유돌근 · 사각근 |
| **두개천골(두개골) 교정** | 두개골 교정(OM) · 두개골 PM 교정 · 두개골 PJ 교정 |
| **척추·흉곽 교정** | 하부흉추 굴곡 · 흉추 신전 · 제1늑골 · 제2늑골 |
| **가동범위(ROM) 측정** | 경추 ROM 측정(굴곡·신전·측굴·회전) |

> 각 술기는 **진단 → 술기 → 재평가**의 임상 흐름을 단계별 서브스텝으로 재현합니다.

## 차별점 · 기대 효과

| 관점 | 효과 |
|------|------|
| **안전·반복** | 실제 환자 없이 **무제한 반복** — 부담 없는 자기주도 학습 |
| **객관적 평가** | 정량 점수·등급으로 **성취도 가시화**, 강사 주관 의존 감소 |
| **몰입 학습** | 3D 가상 환자 + 손 트래킹으로 **실제에 가까운 감각** |
| **교육 관리** | 기관·조·개인별 결과 축적 → **커리큘럼·성취도 관리 도구** |
| **확장성** | 데이터 드리븐 구조로 **신규 술기·커리큘럼 지속 확장** |

## 활용 대상 · 환경

- **대상**: 한의과대학생, 추나 수련의, 한의사 보수·연수 교육
- **환경**: 대학·학회·연수원의 VR 실습실 / 키오스크형 상시 배치
- **기기**: Meta Quest (독립형 VR, 별도 PC 불필요)
