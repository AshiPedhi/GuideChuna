# 제2늑골 · 영상과 텍스트로 재구성한 가이드핸드 초안

원본 영상과 가이드핸드를 나란히 비교하는 별도 시연 자료다. 이번 재구성에는 트래킹 CSV, 이전 시연의 포즈·궤적을 입력하지 않았다. 기존 시나리오·Config·통과 조건·손 데이터는 보존한다.

`review.html`을 열면 비교 영상이 가장 크게 나온다.

- **시작 파지 보기**: 시연 0초, 원본 56.50초에서 멈춘다.
- **팔 한 주기 재생**: 시연 3.75~8.25초, 원본 60.25~64.75초를 재생한 뒤 멈춘다.
- **0.5배 재생**: 느리게 보거나 1배 속도로 되돌린다.
- 청록색은 시술자의 왼손으로 팔을 움직이는 손, 주황색은 오른손으로 흉곽을 지지하는 손이다.

## 입력과 제작 방식

입력은 다음으로 한정한다.

1. 원본 3인칭 `제2늑골 교정기법.MOV`의 56.50~64.75초 영상.
2. 기존 시나리오 `textInstruction`과 내부 사양 문구. 사용한 문구·위치는 `text_evidence.json`에 기록한다.
3. Meta 손 모델의 기본 형태와 관절 연결 정보. 기본 형태는 촬영된 동작 데이터가 아니다.

영상 프레임에서 시술자의 양손과 환자의 어깨·팔꿈치·손목을 직접 관찰하여 화면 좌표를 표시한다. 자동 자세 추정기는 실행하지 않았다. 손 모델의 기본 자세에서 손가락 굽힘과 손바닥 방향을 재구성하고, 주요 자세 사이를 연결하여 시작 파지와 팔 한 주기를 만든다. 이전 초안의 포즈·궤적이나 트래킹 CSV의 관절값을 가져오지 않는다.

이 결과는 26개 관절을 가진 3D 손 메시를 사용하지만, 동작 경로는 단일 시점 영상의 화면 좌표를 중심으로 맞춘 **2.5D 제작 초안**이다. 앞뒤 깊이는 같은 평면(z=0)에 두었다. 가려진 손가락, 손의 비틀림, 절대 길이는 영상만으로 확정할 수 없어 제작 가정으로 남긴다. 관찰값과 제작 가정은 `reconstruction_manifest.json`에 구분한다. 회색 팔 선은 환자의 어깨·팔꿈치·손목 화면 좌표를 연결한 2D 기준선이며, 3D 환자 모델이 아니다.

## 파일

| 파일 | 내용 |
|---|---|
| `review.html` | 비교 영상과 구간 재생 버튼 |
| `comparison.mp4` | 원본 영상과 가이드핸드의 나란한 재생 |
| `start_compare.jpg` | 시작 파지 비교 이미지 |
| `keypose_compare.jpg` | 팔 한 주기의 주요 자세 비교 이미지 |
| `video_text_start.csv` | 새로 재구성한 시작 파지 |
| `video_text_cycle.csv` | 새로 재구성한 팔 한 주기 |
| `video_text_demo.csv` | 시작 파지부터 팔 한 주기까지의 전체 시연 |
| `source_annotations.json` | 원본 영상의 화면 좌표 관찰 기록 |
| `rig_bind_geometry.json` | 사용한 손 모델의 기본 형태 |
| `reconstruction_manifest.json` | 입력·제작 방식·가정 기록 |
| `visual_observation_review.md` | 원본 영상만 별도로 관찰한 검토 |
| `text_evidence.json` | 텍스트 근거와 출처 위치 |
| `validation_report.json` | 원본 보존 및 산출물 검증 결과 |
| `reviewer_check.json` | 비교 화면의 재생·버튼·이미지·링크·화면 폭 검수 결과 |

이 폴더의 CSV는 별도 시연 자료이며 `Assets/Resources/HandPoseData`에 설치하거나 기존 파일을 대체하지 않는다. 기존 통과 조건의 기준 데이터로 등록하지 않는다.

## 확인 범위

화면에서 보이는 시작 파지와 움직임을 원본 영상 옆에서 검토할 수 있도록 만든다. 숨은 손가락의 정확한 관절각, 실제 사람에 대한 좌표 정렬, 접촉 깊이·힘·압력, 임상적 정확성은 이 초안으로 검증하지 않았다. Quest Play 및 실제 환자 적용은 별도 검증이 필요하다. 실제 수행한 파일·재생 검증은 `validation_report.json`을 기준으로 확인한다.

최종 검증은 다음과 같다.

- 생성기에 외부 트래킹 폴더·기존 HandPoseData·이전 시연 폴더를 여는 것을 차단한 상태로 다시 생성해 통과했다. 입력 파일 열기 기록은 `generator_input_audit.json`에 있다.
- 기존 제2늑골 손 데이터 4개, 시나리오·Config, 두 씬의 작업 전후 SHA256이 모두 같다. 기존 손 파일은 원본 보존을 확인하는 해시 바이트로만 읽었으며 동작 입력으로 해석하지 않았다.
- CSV 양손 26관절·30Hz·유한값·정규화 회전과 모델 기본 뼈 길이 보존을 확인했다. 화면 주석 좌표로 되돌리는 산술 검증은 주석과의 일치 검사이며 영상 관찰의 정확도를 실측한 것은 아니다.
- 실제 손 메시 248프레임을 독립 Preview 씬에서 렌더링했다. 비교 영상은 1920×900·30fps·248프레임, 약 8.267초다. 브라우저 재생·시작 보기·한 주기·0.5배와 모든 링크를 확인했다.
- Editor 프로젝트와 참조된 런타임 프로젝트 빌드는 오류 0개, 기존 경고 15개이며 수정 파일의 경고는 없다. `change-impact`는 새 직렬화 충돌 없음, 도구의 씬 인스턴스·코드 참조 각각 0개를 보고했다. 그 밖의 이벤트·나레이션 경고는 이번 변경 밖의 기존 항목이다.

작업 기준 커밋은 `2b3ba80`이며 Quest Play는 미검증 상태다. 이번 C# 수정은 독립 렌더 도구의 출처 표기 두 문장을 일반적인 입력 CSV 표현으로 바꾼 것뿐이다. 검토 절차는 `review.html`에서 **시작 파지 → 팔 한 주기 → 0.5배** 순으로 보는 것이다. 실제 시나리오에는 연결하지 않았으므로 Quest에 설치할 새 실습 동작은 아직 없다.
