# 제2늑골 가이드핸드 시연 초안 — 데이터 제작 근거

2026-10-26 / V0.1 / **원본 키자세 + 영상 대응 제작·추정**

이 자료는 원본 전문가 트래킹의 특정 손 자세를 가져와 영상의 동작 사건에 맞춰 배치한 **검수용 제작 초안**이다. 영상과 트래킹의 정밀 동기화를 완료한 계측 복원본이 아니다. 기존 앱 데이터·시나리오·통과 조건·씬은 수정하지 않았다.

## 가져온 자료와 만든 부분

- 트래킹: `D:/전문가 영상 촬영본/트래킹 데이터/6. 제2늑골 교정기법.csv`
- 비교 영상: `D:/전문가 영상 촬영본/3인칭 시점 카메라/제2늑골 교정기법.MOV`
- 양손의 시작 손가락 모양과 손목 위치·회전은 원본 CSV 61.806초의 포즈를 사용했다.
- 오른손은 흉곽을 지지하는 정지 포즈로 전체 시연에 고정했다.
- 왼손은 시작 파지의 손가락 모양을 유지하고, 손목의 위치·회전만 아래 키자세 사이에서 보간했다.
- 위치는 선형 보간, 회전은 정규화한 최단 경로 Quaternion SLERP를 사용했다.
- 환자 기준 좌표 변환·평행 이동·회전 오프셋·스케일 조정은 하지 않았다. 원본의 `World*` 열이 어떤 환자 기준으로 기록됐는지는 미확인이다.
- 압박력, 환자의 해부학적 각도, 접촉 판정, 통과 조건은 추정하거나 추가하지 않았다.

## 키자세 대응

|---|---:|---:|---:|---:|
| 시작 파지 | 56.50~58.00초 | 0.00~1.50초 | 61.806초 고정 | 1482 |

| 발쪽으로 낮추기 | 62.25초 | 5.75초 | 65.806초 | 1578 |
| 팔 깊게 굽히기 | 63.25초 | 6.75초 | 66.764초 | 1601 |
| 다시 펴기 — 제작상 루프 닫기 | 64.75초 | 8.25초 | 64.598초 포즈 재사용 | 1549 |

이 대응은 제작자가 영상에서 고른 사건에 원본 포즈를 배치한 것이다. 일정한 시간 오프셋으로 동기화한 데이터가 아니다. 각 키자세의 환자 정렬과 손 방향은 실제 손 메시를 적용한 비교 화면에서 검수해야 한다.

‘크게 펴기’의 최초 후보 64.25초는 64.223→64.264초 사이 11.79cm/56.2도의 급격한 원본 변화에 걸려 제외했다. 대신 64.598초를 선택했다. 이 샘플의 직전·직후 변화는 각각 8.4mm/2.24도와 13.6mm/2.09도였다. 이 수치는 주변보다 연속적인 후보를 골랐다는 근거이며, 해당 포즈가 실제 환자와 정확히 일치한다는 검증은 아니다.

## 파일

| 파일 | 내용 | 프레임 수 | Timestamp 범위 |
|---|---|---:|---:|
| `guide_demo_draft.csv` | 시작 파지 정지와 팔 움직임을 포함한 전체 시연 | 248 | 0~8.233333초 |
| `guide_start_draft.csv` | 양손 시작 파지 정지 | 61 | 0~2초 |
| `guide_cycle_draft.csv` | 전체 시연의 3.75~8.25초 부분 | 136 | 0~4.5초 |
| `draft_manifest.json` | 원본 해시, 키자세, 제작 가정, 수치 검증 | — | — |
| `make_rib2_demo.py` | 표준 라이브러리로 새 시연 CSV를 생성하는 스크립트 | — | — |

현재 앱이 고정 30Hz로 프레임을 재생하므로 CSV도 30Hz로 작성했다. 8.25초는 247.5프레임 간격이라 전체 파일은 248프레임이며 마지막 샘플은 8.233333초다. 고정 30Hz 버퍼 길이는 8.266667초다. 정지 파일과 cycle 파일은 끝 샘플을 포함하므로 버퍼 길이가 각각 2.033333초, 4.533333초다.

원본 영상 60.25초와 64.75초를 팔을 편 같은 주기 경계로 보고, 시연 8.25초의 복귀 포즈를 시연 3.75초와 동일한 원본 64.598초 포즈로 제작상 설정했다. **영상 대응을 위해 복귀 endpoint를 시작 wide pose로 설정한 authored loop closure이며 측정값이 아니다.**

최초 초안에서는 복귀에 원본 67.890초 포즈를 사용해 cycle의 시작과 끝 손목이 약 12.7cm/49.1도 달랐다. 원본 영상의 같은 주기 경계를 표현하기 위해 이 후보를 위와 같이 교체했으며, 원본 CSV는 그대로 보존했다. cycle 파일은 0초와 4.5초 끝 샘플을 모두 포함한 136프레임으로, 두 경계의 손목·손가락 포즈가 정확히 같다. 위치와 회전은 이어지지만, 경계 속도까지 연속이 되도록 곡선을 맞춘 것은 아니다.

전체 demo 파일의 마지막 샘플은 8.233333초이므로 수학적 endpoint 8.25초에 조금 못 미친 보간 포즈다. 정확히 닫힌 한 주기가 필요하면 끝 샘플이 포함된 cycle 파일을 사용한다.

## 검증한 것

- 프레임마다 양손 각각 26관절, 총 52행.
- 앱이 사용하는 18열 형식과 연속 프레임 인덱스.
- `World*` 열은 손목 JointID=1에만 기록, JointID=0은 손바닥.
- 모든 출력 수치가 유한값이고 Timestamp 간격이 1/30초.
- 오른손의 root와 양손 로컬 손가락 포즈가 고정됨.
- cycle 파일의 첫 샘플과 끝 샘플에서 양손의 모든 포즈 열이 같고, Timestamp만 0초와 4.5초로 다름.
- 전체 시연 왼손 최대 프레임 이동 약 10.3mm, 최대 프레임 회전 약 2.75도. 이는 제작된 보간의 수치이며 전문가 움직임 실측값이 아니다.
- 원본 트래킹의 SHA256이 생성 전후 동일함.

## 검수 전 남은 것

영상과 트래킹의 정밀 동기화, 원본 포즈와 실제 환자의 위치 일치, 움직이는 동안 고정한 손가락 모양의 적합성, Unity/Quest에서의 실제 재생·환자 정렬은 별도 검수가 필요하다. 이 자료로 기존 통과 조건을 교체하거나 전문가의 정확한 연속 계측 데이터라고 표시하면 안 된다.

실제 손 메시의 다섯 키자세를 비교할 때는 시작 파지를 `guide_start_draft.csv`의 프레임 0에서, 나머지 네 키를 `guide_cycle_draft.csv`의 프레임 0·60·90·135에서 읽으면 정확한 키 샘플을 사용할 수 있다.
