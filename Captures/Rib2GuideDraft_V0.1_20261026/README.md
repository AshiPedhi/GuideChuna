# 제2늑골 · 원본과 가이드핸드 시연 초안

2026-10-26 · V0.1 · 별도 검토용 자료

**시작 파지와 팔 움직임 한 주기를 원본 영상 옆에서 비교하는 초안이다.** 기존 `Resources`의 데이터, 실습 시나리오, 통과 조건은 바꾸지 않는다.

## 보는 방법

1. 같은 폴더의 `review.html`을 연다. 영상 왼쪽이 원본, 오른쪽이 가이드핸드다.
2. **시작 파지 보기**를 누르면 처음 자세에서 멈춘다. **팔 한 주기 재생**을 누르면 해당 구간만 재생한다.
3. 손 방향과 이동 흐름을 천천히 보려면 재생 속도를 **0.5배**로 바꾼다.

청록은 팔을 움직이는 **왼손**, 주황은 흉곽을 지지하는 **오른손**이다. 색과 좌우 명칭은 시술사의 손 기준이다. 화면에 보이는 크기와 위치를 실제 환자의 접촉 위치나 각도로 읽으면 안 된다.

## 원본과 제작 보정의 구분

| 구분 | 이번 초안에 사용한 것 |
|---|---|
| 입력 자료 | 전문가의 제2늑골 3인칭 영상과 함께 보관된 원본 트래킹 CSV |
| 원본에서 가져온 것 | 시작 파지의 양손 26관절 포즈, 선택한 왼손 손목의 위치·회전 |
| 제작한 것 | 영상의 사건에 맞춘 키자세 타이밍, 키 사이의 위치·회전 보간, 주기 끝을 시작 자세로 되돌리는 보정 |
| 고정한 것 | 흉곽 지지 오른손 전체 포즈와 양손 손가락 모양 |
| 미검증 | 영상과 트래킹의 정밀 동기화, 실제 환자와의 3D 정렬, 움직이는 동안 손가락 모양의 적합성, Quest Play |

영상의 손 위치만으로 전체 3D 동작을 자동 복원한 결과는 아니다. 함께 보관된 원본 트래킹의 키자세를 사용했다. 영상에서 구간을 고르고 그 흐름에 맞춰 별도 가이드 데이터를 제작했다.

## 비교 범위

- 원본 영상: **56.50~64.75초**.
- 전체 시연: 시작 파지 정지, 전환, 팔 한 주기. 약 **8.25초**.
- 팔 한 주기: 시연의 **3.75~8.25초**. 펴기 → 낮추기 → 굽히기 → 다시 펴기.
- 오른손과 시작 손가락 모양: 원본 트래킹 **61.806초**의 포즈.
- 왼손 손목: 원본의 주요 포즈 사이를 위치는 선형, 회전은 Quaternion SLERP로 보간.

한 주기의 끝 자세는 영상의 반복 경계에 맞춰 시작의 ‘팔 펴기’ 포즈를 재사용했다. **끝 자세의 일치는 제작 보정이며 실측 결과가 아니다.** 주기 CSV의 양끝 포즈는 같지만, 경계 속도까지 매끄럽게 맞춘 것은 아니다.

## 확인한 범위

CSV의 열 형식, 연속 프레임, 양손 26관절, 30Hz 간격, 유한값, 고정 포즈, 주기 양끝 일치를 수치로 확인했다. 원본 트래킹은 내보내기 전후 해시가 같다. 원본 키자세와 제작된 보간의 구체적인 수치는 `draft_manifest.json`과 `DATA_PROVENANCE.md`에 기록했다.

이 자료는 Unity의 별도 Editor 미리보기로 손 메시를 보여 주는 검토용 초안이다. 실제 환자 정렬 및 임상 적합성 검수, Quest에서의 Play 검증은 수행하지 않았다.

최종 확인 결과는 `validation_report.json`에 있다. 작업 전후 비교한 원본 12개(기존 손 데이터 4개, 시나리오·Config, 두 씬, 외부 영상·트래킹)의 SHA256이 모두 같다. 실제 Meta 손 메시와 양손 26관절을 별도 Preview 씬에서 248프레임 렌더링했고, 비교 영상은 1920×900·고정 30fps·248프레임으로 확인했다. 브라우저에서 재생, 구간 이동, 0.5배, 정지 화면 링크를 확인했다.

런타임 및 Editor 프로젝트 빌드는 오류 0개이며 새 도구의 경고는 없다. 기존 경고는 각각 14개·15개다. `change-impact`에서 새 도구의 씬 인스턴스·코드 참조는 각각 0개였다. 검사기가 `Request.width/height`를 기존 씬의 같은 이름과 연결한 것은 이름 일치에 따른 오탐이다. 두 필드는 독립 JSON 요청 데이터이며 씬 필드가 아니다. 나머지 이벤트·나레이션 경고는 이번 변경 대상 밖의 기존 항목이다.

현재 검토 절차는 `review.html`에서 시작 파지, 한 주기, 0.5배를 차례로 보는 것이다. 이번 초안은 실행 중인 시나리오에 연결하지 않았으므로 Quest Play로 확인할 새 동작은 아직 없다. 향후 연결할 때 환자 정렬과 실제 접촉 부위를 먼저 검수해야 한다.
