청록은 **시술자 왼손: 환자 오른손·손목을 잡고 팔을 유도하는 손**, 주황은 **시술자 오른손: 흉곽을 지지하는 손**이다.

Unity에서 **GuideChuna → 시험 → 제2늑골 → 양손 영상 가이드 초안 (독립 검토)**를 연다.
Play나 씬 전환 없이 다음 순서로 확인한다.

1. `시작 파지`에서 양손 위치를 본다.
2. `팔 한 주기`로 팔 펼침 → 발 쪽 이동 → 깊게 굽힘 → 다시 펼침을 본다.
3. `일시정지`와 시간 슬라이더로 자세를 멈추고 `0.5배`로 천천히 살펴본다.
4. `검토 시점`의 SourceOblique / Top / Side와 확대를 바꿔 손·환자 관계를 확인한다.

창의 왼쪽은 같은 시각의 원본 프레임이고 오른쪽은 별도 환자와 실제 손 메시다.
원본 56.50초부터 약 64.73초까지, 이미 파지한 상태와 팔 한 주기를 보여준다.
접근부터 손을 놓는 시점까지의 전체 시술이나 무한 반복 궤적은 아니다.

## 구현과 가정

`Assets/Editor/Rib2HandsVideoReviewWindow.cs`는 기존 V01을 private Preview Scene으로 읽고
`data.csv`를 임시 TextAsset으로 만들어 복제본에만 할당한다. 기존 c9·프리팹·CSV를 저장하지 않는다.
`Rib2VideoTextScenePlayer.Seek` → `Rib2DemoPatientArm.Evaluate`의 실제 시연 함수를 사용한다.
현재 본을 CPU BakeMesh로 그려, 여러 자세를 연속 촬영할 때 GPU 스킨이 뒤처지는 문제를 피한다.
새 inspector 직렬화 필드나 실습 시나리오 연결은 없다.

환자는 기존 독립 V01의 c9 복제본이다. 팔 연결은 표시용 2본 풀이이며,
이전 해부학 리그의 자유 조작·장력 솔버가 통합된 것은 아니다.

양손 역할과 움직임 순서는 이번에 원본 3인칭과 바디캠을 재확인했다.
입력 포즈는 9개 수작업 영상 관찰점·텍스트·일반 손 모델 기본 형태에서 제작한 기존 영상 전용 초안이다.
새 추적기나 전문가의 손 녹화를 실행한 결과는 아니다.
손가락은 손별 고정 파지 초안이다. 깊이·손 비틀림·가려진 손가락·절대 배율은 가정이다.
흉곽의 정확한 늑골 접촉점, 힘·압력·장력은 재현하거나 측정하지 않았다.
양 카메라는 동기화·보정된 다중 시점으로 간주하지 않았다.

이 V02는 이미 존재하므로 재실행해 덮어쓰지 않는다. `--verify-preservation`으로 보존 해시를 다시 확인할 수 있다.
